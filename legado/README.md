# Protótipos antigos

Estes arquivos ficavam soltos na raiz e não entram no build. O Maven compila só `src/` e `tests/`.

São rascunhos anteriores do catálogo e dos favoritos. Vários usam outro modelo de `Track` (`getId()`, `durationInSeconds`) e não compilam junto com o código atual.

Cópias idênticas com nomes como `(1)` e `6` foram reduzidas a um arquivo. A versão que o programa usa está em `src/`.

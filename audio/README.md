# Áudios do catálogo inicial

Os oito arquivos MP3 desta pasta são faixas instrumentais de demonstração geradas para que o catálogo inicial possa ser reproduzido sem depender de internet ou de arquivos comerciais. Os nomes correspondem aos caminhos usados em `src/CatalogService.java`.

Eles não são cópias das gravações originais associadas aos títulos exibidos no catálogo. Para usar gravações próprias ou licenciadas, substitua os arquivos mantendo os mesmos nomes e o formato MP3 suportado pelo player.
